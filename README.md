# Student Analytics Toolkit

**Author:** Kuhlekonke Phungula
**Cohort:** Data Science - Melsoft Academy
## Description
A terminal-based Student Analytics Toolkit built in Python. It generates a messy sample dataset, cleans it, models each row as a 'Student' object, runs analysis over the class (averages, pass rate, top student), and writes report and log files back to the disk. It is built entirely on the Python standard library and brings together everything from Python Essentials 2: OOP, string cleaning, file handling, generators, closures, and the standard library. 
## How to run
python main.py
## Features
1. Generate sample data file
2. Load & clean records from file
3. View all students
4. Analyse (averages, pass/fail, top student)
5. Filter students (generator)
6. Grade with a custom pass mark (closure)
7. Environment & date report
8. Export results to a file
9. Exit
